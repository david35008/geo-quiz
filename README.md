# Geo Quiz

A single-file HTML game to test your knowledge of country flags, capitals, and basic words in different languages.

## How to play

Open `index.html` in any modern browser — no build step or server required.

1. Enter your name on first visit (saved in localStorage).
2. Choose a mode: **Flags**, **Capitals**, or **Words**.
3. Swipe toward one of four answers (up / down / left / right), or tap a direction label.
4. Complete 10 questions per round; difficulty increases each round.

## Features

- Three quiz modes with progressive difficulty (5 tiers, 69 countries)
- Swipe-based controls with desktop click fallback
- Scoring with speed and streak bonuses
- Progress saved locally per player and mode
